# 登录页美化与无滚动条重构技术设计

## 背景

当前登录页面存在两个主要问题：
1. **视觉美观度不足**：背景色调过于深沉黑暗，与卡片左侧亮丽的湖青色（#25B7AA）不搭，不符合医疗供应链管理系统的专业、干净、现代化的定位。
2. **布局溢出产生滚动条**：在 660px 默认高度下，右侧表单中的各种元素（包含业务域单选、科室选择、图形验证码等）过多，导致产生了一条显眼的灰色垂直滚动条，严重影响视觉质量。
3. **编译/类型错误**：代码中由于包含未定义变量 `setCaptchaInput` 以及在 `ProFormText` 上直接使用 `onChange` 等问题，导致 `pnpm tsc` 类型检查报错。

## 设计目标

1. **背景优化**：采用简约、美观、清凉的亮色渐变背景（经典浅湖青渐变 `#f3faf9` 到 `#dcf2f0`），搭配柔和的青绿色卡片发光阴影，营造专业且现代化的视觉效果。
2. **彻底消灭滚动条**：限制卡片高度为 630px，缩减右侧表单所有控件的 `marginBottom`，并在容器上施加 `overflow: hidden`，保证任何情况下都不会出现滚动条。
3. **欢迎登录与 Logo 同行对齐**：Logo 高度由 `24px` 放大调整为 `34px`，文字字号对应由 `20px` 放大调整为 `26px` 且加粗；整体 marginTop 调整为 `6px`，更显饱满。
4. **副标题与表单间距极限缩小（消除红框空白）**：在 `LoginForm` 的 `contentStyle` 中引入 `marginTop: '-18px'`，并将首个输入框 `username` 的 `marginTop` 降为 `0`，从而完美抹除 ProComponents 自带的约 30px-40px 的大片空白顶部。
5. **耗材业务域作为默认选择并置于左侧**：将“耗材业务域”作为默认选项且渲染在选项栏的左侧。
6. **表单有效宽度增加**：将右侧 `loginPanel` 宽度微调至 `480px`，同时把左右 `padding` 从 `48px` 缩减至 `36px`，使得表单实际可容纳宽度增加 `44px`，以支持更长的科室名称完整展示。
7. **修复全部编译与类型错误**：补充 `captchaInput` 状态定义，修复 `onChange` 的类型绑定，通过 `pnpm tsc`。

## 方案选型与决策

### 背景色调决策

* **方案 A（已否决）**：深色调微暗渐变（混合湖青色与深蓝色）。
  * *原因*：用户反馈黑色背景不符合预期，暗色调在此项目中与洁净医疗的主题容易冲突，视觉略显压抑。
* **方案 B（采纳）**：经典清爽浅湖青渐变（`#f3faf9` 至 `#dcf2f0`）。
  * *原因*：与系统品牌色 `#25B7AA` 完美契合，明亮干净，符合简约美观的设计期望。

### 防滚动条溢出方案

* 对右侧 `loginPanel` 显式声明 `overflow: 'hidden'`。
* 将表单项的下边距（`margin-bottom`）从 `14px`/`16px` 全面缩减至 `10px`，并将 Logo 高度调为 `40px`，从而在 `630px` 的卡片内部完美盛载所有组件。

## 影响范围

* 受到修改的文件：`src/pages/user/login/index.tsx`。
* 不影响其他任何业务模块。
